# 評価データ分析ツール

Excel 2019（VBAのみ）で動作する、複数年度・複数期別の評価分布を比較するための
教育効果分析ツールです。PowerQuery・Office 365専用機能・外部DLL・外部ライブラリは
一切使用せず、Excel標準機能とVBAのみで実装しています。

## リポジトリ構成

```
vba/
  modules/            VBAソース（標準モジュール、.bas）
    mod_Common.bas      共通定数・汎用ヘルパー
    mod_Logging.bas     ログ記録
    mod_Database.bas    スキーマ初期化・CRUD
    mod_Import.bas      データ取込ウィザード
    mod_Analysis.bas    分析処理の司令塔
    mod_Statistics.bas  統計計算（純粋関数）
```

## なぜソースコードと.xlsmを分けているか

VBAプロジェクト（フォームコントロールを含む）はExcelのバイナリ内部形式で
保持されており、テキストのGit差分として管理・レビューするのに適しません。
本プロジェクトでは **VBAソース（`vba/modules/*.bas` などのテキストファイル）を正**とし、
`.xlsm` はソースからいつでも再生成できるビルド成果物として扱います。
これにより、10年単位の保守でも「どのコードが正か」が常に明確になり、
差分レビュー・バージョン管理・障害復旧が容易になります。

`.xlsm` そのものはこのリポジトリには含めていません。
`vba/build/BUILD_README.md` の手順に従って、Windows版Excel 2019で
数分程度で組み立てられます。

## クイックスタート

1. `vba/build/BUILD_README.md` の手順に従ってビルドし、
   `評価データ分析ツール.xlsm` を作成する。
2. ブックを開くと「ホーム」画面が表示される。
3. 「(1) データ取込」ボタンから外部Excelファイルを取り込む。
4. 「(2) 分析」で年度・期別・評価項目を選び、「分析実行」を押す。

詳しい操作方法は `docs/05_ユーザーマニュアル.md` を参照してください。

## 開発条件の遵守

- Excel 2019標準機能のみ使用（PowerQuery・Office 365専用機能・外部DLL・外部ライブラリ不使用）
- フォームコントロール（Excel標準のボタン・リストボックス等）のみを使用し、
  ActiveXコントロールは使用しない
- 全モジュール `Option Explicit` を徹底
- 縦持ち（ロング形式）データ構造により、評価項目数の増減にコード変更不要
