# 処理フロー図

## 1. データ取込フロー（①〜⑨）

```mermaid
flowchart TD
    A[① データ取込ボタン押下] --> B[外部Excelファイルを選択]
    B -->|キャンセル| Z1[中断・ログ記録]
    B --> C[② 外部ブックを読み取り専用で開く]
    C -->|開けない/破損| E1[エラーメッセージ表示・ログ記録・処理終了]
    C --> D[② シート一覧を取得]
    D --> F[③ シート名・見出し内容から\n総合成績シート候補を自動判定]
    F --> G[④ シート一覧をリストボックスに表示\n候補を自動選択]
    G --> H[利用者が「シート決定」を押す]
    H --> I[⑤ 見出し行を自動検出し\n列見出し・サンプル値を取得]
    I --> J[⑥ 列ごとにマッピング候補を提示\n学生番号/氏名/クラス/年度/評価項目]
    J --> K[⑦ 利用者がドロップダウンで\n必要に応じてマッピングを修正]
    K --> L[「内容確認へ」ボタン押下]
    L --> M[⑧ 対象行数・スキップ件数・\n重複件数・新規項目数を集計して表示]
    M --> N{内容は妥当か}
    N -->|キャンセル| Z2[外部ブックを保存せず閉じる・ログ記録]
    N -->|登録| O[⑨ 登録処理開始]
    O --> P[新規評価項目をT_Itemsへ作成]
    P --> Q[行ごとに学生番号・氏名の空欄チェック]
    Q -->|空欄| Q1[スキップしカウント]
    Q -->|OK| R[項目ごとに重複チェック]
    R -->|重複かつ上書き無効| R1[スキップしカウント]
    R -->|重複かつ上書き有効| R2[既存行を直接更新]
    R -->|新規| R3[登録候補として保持]
    R1 --> S
    R2 --> S
    R3 --> S[次の項目/次の行へ]
    S --> T[T_Scoresへ一括追加]
    T --> U[対象の年度・クラスの\n総合評価を再計算]
    U --> V[外部ブックを保存せず閉じる]
    V --> W[結果サマリーを表示・ログ記録]
    W --> X[画面をリセットし待機状態へ]
```

## 2. 分析実行フロー

```mermaid
flowchart TD
    A[「分析実行」ボタン押下] --> B[年度・クラスコード・評価項目の選択を取得]
    B --> C{いずれかが未選択}
    C -->|Yes| C1[警告メッセージを表示し終了]
    C -->|No| D[T_Scoresから条件に一致する点数を抽出]
    D --> E{該当データあり}
    E -->|No| E1[「該当データなし」を表示し終了]
    E -->|Yes| F[基本統計量を計算\n平均/中央値/最頻値/標準偏差/最大/最小/四分位数]
    F --> G[個人別一覧（偏差値）を計算]
    G --> H[グラフ設定を取得\nビン数or幅・正規分布重畳・年度重畳]
    H --> I[① ヒストグラムを更新]
    I --> J[② 累積分布曲線を更新]
    J --> K[③ 箱ひげ図を更新]
    K --> L[統計表・個人別一覧を画面へ反映]
    L --> M[ログ記録]
```

## 3. 評価項目の重み変更フロー

```mermaid
flowchart TD
    A[設定画面でT_Itemsの重み・表示名を編集] --> B[「反映」ボタン押下]
    B --> C[mod_Settings.ApplyItemSettingsChanged]
    C --> D[mod_Database.RecalcSummary 全件実行]
    D --> E[T_Scores×T_Itemsの重みから\n学生ごとに加重平均を再計算]
    E --> F[T_Summaryを更新（Upsert）]
    F --> G[ログ記録・完了メッセージ表示]
```

## 4. エラー処理の共通フロー

```mermaid
flowchart TD
    A[各プロシージャの処理開始] --> B[On Error GoTo ErrHandler]
    B --> C[通常処理を実行]
    C -->|正常終了| D[Exit Sub/Function]
    C -->|例外発生| E[ErrHandler ラベルへジャンプ]
    E --> F[画面更新等を後始末\nBeginBusyで停止していれば EndBusy]
    F --> G[開いていた外部ブックがあれば\n保存せずに閉じる]
    G --> H[mod_Common.HandleError を呼び出し]
    H --> I[T_Logへエラー内容を記録]
    I --> J[利用者へメッセージボックスで通知]
```

主な想定エラーと対応（詳細は `docs/03_データベース設計書.md` および
各モジュールのコメントを参照）:

| 事象 | 対応 |
|---|---|
| シート名変更 | シート名＋見出し内容の両面から候補を推定。誤っていれば利用者が一覧から選び直せる |
| 列名変更 | 見出しの部分一致・正規化比較でマッピング候補を推定。ドロップダウンで修正可能 |
| 列順変更 | 列位置ではなく見出し文字列でマッピングするため影響を受けない |
| 空データ（学生番号/氏名が空欄） | その行をスキップし件数を集計・表示 |
| 重複登録 | 既定はスキップ。「上書き」チェックで既存データの更新も可能 |
| 途中キャンセル | 各ステップに用意されたキャンセル操作で、外部ブックを保存せず閉じて中断。
  内部テーブルへの書き込みは⑨の最終段階でのみ行うため、中間状態が
  内部データに残ることはない |
| ファイル破損 | `Workbooks.Open` のエラーを捕捉し、メッセージ表示・ログ記録の上で処理を終了 |
