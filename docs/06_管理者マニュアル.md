# 管理者マニュアル

対象読者: 評価項目の設定・データ容量の管理を行う管理者
（一般利用者向けの操作は `05_ユーザーマニュアル.md` を参照してください）。

管理者・一般利用者とも同じExcelブックを使用します。権限による
画面の出し分けは行っていません（規模・運用形態を踏まえ、
ファイル共有時のアクセス権限やパスワード等、Excel外の運用ルールで
管理する想定です）。

## 1. 評価項目の管理（表示名・重み）

1. 「設定」画面を開きます。
2. 画面上部の表（T_Items）に、これまでに登録された評価項目が
   一覧表示されます。
   - 「表示名」列: 分析画面やグラフに表示される名称です。セルを
     直接編集して自由に変更できます。
   - 「重み(%)」列: 総合評価の計算に使用する重みです。0〜100の
     範囲で入力します。複数の項目の重みが必ずしも合計100%に
     なる必要はありません（相対的な重み付けとして扱われます）。
   - 「有効」列: FALSE にすると、分析画面の選択肢から除外されます
     （データそのものは削除されません）。
3. 編集が終わったら「反映（総合評価を再計算）」ボタンを押してください。
   これにより、登録済みの全学生の総合評価が新しい重みで再計算されます。

評価項目は、データ取込時に元データの列を「新規評価項目」として
マッピングすると自動的に追加されます。項目数の上限はなく、
3項目・4項目・5項目・10項目のいずれの構成でも運用できます。

## 2. 詳細設定（T_Settings）

「設定」画面右側の表で、以下の値を編集できます。
通常は初期値のままで問題ありませんが、必要に応じて変更してください。

| 設定キー | 内容 |
|---|---|
| HIST_BIN_MODE | ヒストグラムのビン指定方法の既定値（COUNT または WIDTH） |
| HIST_BIN_COUNT | ビン数指定時の既定ビン数 |
| HIST_BIN_WIDTH | ビン幅指定時の既定ビン幅 |
| GRAPH_SHOW_NORMAL | 正規分布重畳表示の既定値（TRUE/FALSE） |
| GRAPH_OVERLAY_YEARS | 複数年度重畳表示の既定値（TRUE/FALSE） |
| LOG_MAX_ROWS | ログの最大保持件数（これを超えると古い記録から自動削除） |

## 3. 列マッピングテンプレートの管理

データ取込画面で保存したテンプレートは「設定」画面の
「保存済みテンプレート」一覧に表示されます。不要になったテンプレートは
一覧から選択し「選択したテンプレートを削除」ボタンで削除できます。

## 4. データの削除（容量管理）

「データベース」画面で、不要になった年度・期別単位のデータを
完全に削除できます。

1. 「データベース」画面を開きます。
2. 「年度指定（削除用）」「期別指定（削除用）」に、
   削除したい年度・期別を入力します。
3. 「指定データを削除」ボタンを押します。
4. 確認ダイアログが表示されるので、内容を確認して「はい」を選択します。

**この操作は元に戻せません。** 実行前に必要なデータが揃っているか
必ず確認してください。削除すると、該当する評価点数（T_Scores）と
総合評価キャッシュ（T_Summary）の両方が削除されます。

「再集計・更新」ボタンは、何らかの理由で総合評価の値に不整合が
疑われる場合に、全件を再計算するためのものです。

## 5. ログの管理

「ログ」画面から、不要になった操作履歴を「ログを全件クリア」ボタンで
削除できます。ログは既定で最大5000件まで自動保持され、それを超えると
古い記録から自動的に削除されるため、通常は手動でのクリア操作は
必須ではありません。

## 6. 長期運用における容量管理の考え方

- 元Excel（外部ファイル）は一切保存されないため、取込を繰り返しても
  元ファイル分の容量は増加しません。
- 評価点数は縦持ち形式のため、項目数が増えても列（テーブル構造）が
  増えることはなく、行数のみが緩やかに増加します。
- 数年に一度、過去年度で今後参照しないデータを「データベース」画面から
  削除することで、ファイルサイズの増加を抑えられます。
- ログは自動的に上限管理されるため、際限なく増加することはありません。
