# 画面設計書

## 1. 画面共通仕様

- すべての画面はワークシートそのもの（可視シート）として実装する。
  別ウィンドウのユーザーフォームは使用せず、シート上に配置した
  **Excel標準の「フォームコントロール」**（ボタン・リストボックス・
  チェックボックス・オプションボタン）で操作する。
  ActiveXコントロールは使用しない（長期利用時の環境依存不具合を避けるため）。
- 各シートの1行目に共通ナビゲーションバー（6ボタン）を配置し、
  どの画面からでも他の画面へ1クリックで移動できる。
- 画面の生成・再構築は `mod_UI.SetupAllSheets`（各画面ごとに
  `mod_UI.SetupXxxSheet`）が担当する。セル位置・コントロール名は
  すべて `mod_Common` の定数として一元管理されており、レイアウトを
  変更する場合はこの定数を書き換えるだけでよい。
- ボタンの `OnAction` にはすべて `モジュール名.プロシージャ名` の
  形式でマクロを割り当てる（例: `mod_UI.Btn_Import_Start`）。

ナビゲーションバー（全画面共通、1行目）:

| コントロール名 | 配置範囲 | 表示文字 | 遷移先 |
|---|---|---|---|
| btnNavHome | B1:C1 | ホーム | ホーム |
| btnNavImport | D1:E1 | データ取込 | データ取込 |
| btnNavAnalysis | F1:G1 | 分析 | 分析 |
| btnNavSettings | H1:I1 | 設定 | 設定 |
| btnNavDatabase | J1:K1 | データベース | データベース |
| btnNavLog | L1:M1 | ログ | ログ |

## 2. ホーム画面（シート名「ホーム」）

利用者が最初に開く画面。5つの大きなボタンで各機能へ遷移する。

| セル/コントロール | 内容 |
|---|---|
| B2 | タイトル「評価データ分析ツール」（太字・14pt） |
| B3 | バージョン表記 |
| btnHomeImport（B5:D6） | 「① データ取込」→ データ取込画面へ遷移し、取込ウィザードを自動開始 |
| btnHomeAnalysis（B8:D9） | 「② 分析」→ 分析画面へ遷移 |
| btnHomeSettings（B11:D12） | 「③ 設定」→ 設定画面へ遷移 |
| btnHomeDatabase（B14:D15） | 「④ データベース」→ データベース画面へ遷移 |
| btnHomeLog（B17:D18） | 「⑤ ログ」→ ログ画面へ遷移 |
| F5（結合 F5:J10） | ダッシュボード要約（登録年度数・学生延べ件数・レコード数） |

ホーム画面を表示するたびに `mod_UI.RefreshHomeSummary` が要約を再計算する。

## 3. データ取込画面（シート名「データ取込」）

利用者は「データ取込を開始」ボタンを押すだけで、ウィザード形式で
①〜⑨の手順が進行する。各ステップの表示・非表示は
`mod_UI.ShowImportStep` が切り替える。

| セル/コントロール | ステップ | 内容 |
|---|---|---|
| B2 | - | タイトル |
| B3 | - | 状態メッセージ（進捗・エラー案内） |
| B4 | ① | 案内文 |
| btnImpSelectFile（B5:C5） | ① | 「データ取込を開始」ボタン。ファイル選択ダイアログを表示 |
| D5:H5（結合） | ① | 選択したファイルパスの表示（読み取り専用） |
| B7 | ②③ | 案内文 |
| lstImpSheets（B8:E14） | ②③④ | シート一覧リストボックス。総合成績シート候補が自動選択される |
| G9:H9（結合） | - | 年度（手入力）。元データに年度列が無い場合に使用 |
| G11:H11（結合） | - | クラスコード（手入力）。元データにクラス列が無い場合に使用 |
| btnImpConfirmSheet（B15:C15） | ④ | 「シート決定」ボタン |
| B17 | ⑤⑥ | 案内文 |
| B19:D19 | ⑤⑥ | マッピング表ヘッダー（元の見出し／サンプル値／マッピング先） |
| B20:D49 | ⑤⑥⑦ | マッピング表本体（最大30列分）。マッピング先はドロップダウン選択 |
| btnImpProceedConfirm（B51:C51） | ⑦→⑧ | 「内容確認へ」ボタン |
| btnImpSaveTemplate（E51:G51） | - | 「テンプレート保存」ボタン（現在のマッピングを名前を付けて保存） |
| B52 | ⑧ | 案内文 |
| B53:H59 | ⑧ | 登録内容の確認サマリー（対象行数・スキップ件数・重複件数等） |
| chkImpOverwrite（B60:D60） | ⑨ | 「既存データを上書きする」チェックボックス |
| btnImpCommit（B62:C62） | ⑨ | 「登録」ボタン |
| btnImpCancel（E62:F62） | 全体 | 「キャンセル」ボタン（ステップ1以降、常時表示） |

列T（`IMP_MAPPING_HELPER_COL`）はマッピング先ドロップダウンの選択肢一覧を
保持する非表示ヘルパー列であり、利用者操作の対象ではない。

## 4. 分析画面（シート名「分析」）

| セル/コントロール | 内容 |
|---|---|
| B2 | タイトル |
| B4/D4/F4 | 「年度」「クラスコード」「評価項目」ラベル |
| lstAnlYears（B5:C12） | 年度リストボックス（複数選択可） |
| lstAnlClasses（D5:E12） | クラスコードリストボックス（複数選択可） |
| lstAnlItem（F5:G12） | 評価項目リストボックス（単一選択） |
| chkAnlNormal（I5:K5） | 「正規分布を重畳表示」チェックボックス（既定ON） |
| chkAnlOverlay（I6:K6） | 「複数年度を重畳表示」チェックボックス（既定ON） |
| optAnlBinCount（I8:J8）+ K8 | 「ビン数指定」オプションボタン＋ビン数入力欄 |
| optAnlBinWidth（I9:J9）+ K9 | 「ビン幅指定」オプションボタン＋ビン幅入力欄 |
| btnAnlRun（B14:C14） | 「分析実行」ボタン |
| chtAnlHistogram（B16:H26） | ① ヒストグラム（正規分布重畳可） |
| chtAnlCumulative（B27:H37） | ② 累積分布曲線 |
| chtAnlBoxplot（B38:H48） | ③ 箱ひげ図（Excel標準の「箱ひげ図」チャート種類を使用） |
| B50〜 | 基本統計表（件数・平均・中央値・最頻値・標準偏差・最小値・
  第1四分位数・第3四分位数・最大値） |
| E49〜 | 個人別一覧（学生番号・氏名・点数・偏差値）。最大260行まで表示 |

「分析実行」を押すと `mod_Analysis.RunAnalysis` が選択条件を集計し、
統計表・個人別一覧・3種類のグラフをすべて更新する。

## 5. 設定画面（シート名「設定」）

| セル/コントロール | 内容 |
|---|---|
| B2/B3 | タイトル・案内文 |
| B4〜 | T_Items（評価項目マスタ）テーブル。表示名・重み(%)のセルを
  直接編集できる |
| btnSetApply（B30:D30） | 「反映（総合評価を再計算）」ボタン |
| I3 | 詳細設定の案内文 |
| I4〜 | T_Settings（キー・バリュー設定）テーブル。ヒストグラムの既定ビン数、
  ログ最大保持件数などを直接編集できる |
| I12 | 「保存済みテンプレート」ラベル |
| lstSetTemplates（I13:J20） | テンプレート一覧リストボックス |
| btnSetDeleteTemplate（I22:J22） | 「選択したテンプレートを削除」ボタン |

評価項目テーブルは行数が可変（項目数に応じて増減）のため、
右側のコントロール群は十分な余白を空けたI列以降に配置している。

## 6. データベース画面（シート名「データベース」）

| セル/コントロール | 内容 |
|---|---|
| B2/B3 | タイトル・案内文 |
| B4〜 | T_Summary（学生ごとの総合評価）テーブル。オートフィルタで
  年度・クラスを絞り込み可能 |
| I4/J4 | 削除対象の年度指定ラベル／入力欄 |
| I5/J5 | 削除対象のクラスコード指定ラベル／入力欄 |
| btnDbDeleteGroup（I6:J6） | 「指定データを削除」ボタン（確認ダイアログあり） |
| btnDbRefresh（I8:J8） | 「再集計・更新」ボタン |

本画面は学生別の集計値（総合評価）を表示する。評価項目ごとの
明細（点数）は「分析」画面で確認する。

---

## 7. ログ画面（シート名「ログ」）

| セル/コントロール | 内容 |
|---|---|
| B2/B3 | タイトル・案内文 |
| B4〜 | T_Log（操作・エラーログ）テーブル |
| btnLogClear（I4:J4） | 「ログを全件クリア」ボタン（確認ダイアログあり） |

保持件数が上限（既定5000件、設定画面で変更可）を超えると、
古い記録から自動的に削除される（容量対策）。
