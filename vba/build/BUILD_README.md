# ビルド手順書（VBAソース → 評価データ分析ツール.xlsm）

このフォルダの `modBuildTool.bas` は、`vba/modules` 配下のVBAソース一式から
実際に動作する Excel マクロ有効ブック（.xlsm）を自動組み立てするための
ツールです。

なぜソースコードと完成品(.xlsm)を分けて管理しているか：
VBAプロジェクト（フォーム・ボタン等を含む）はExcelのバイナリ内部形式で
保持されており、テキストのGit差分として管理・レビューするのに適しません。
本プロジェクトでは **VBAソース（.bas テキストファイル）を正とし、
.xlsm はソースからいつでも再生成できるビルド成果物** として扱います。
これにより、10年単位の保守でも「どのコードが正か」が常に明確になります。

## 前提条件

- デスクトップ版Excel（マクロ有効ブック(.xlsm)とVBEを扱えるもの）。
  Windows版 Excel 2019 のほか、**Windows版／Mac版 Microsoft 365 Excel でも
  同様の手順でビルド可能**です（ブラウザ版・iPad版のExcelは不可）。
  完成した .xlsm 自体はExcel 2019標準機能のみで作られているため、
  どの版で開いても同じように動作します。
- 管理者権限は不要ですが、VBAのIDE操作を行うため以下の設定が必要です
  （Windowsの場合。Macの場合は下記「Mac版での注意事項」を参照）。

### 1. マクロのセキュリティ設定（Windows）

1. Excelを開く → [ファイル] → [オプション] → [トラストセンター] →
   [トラストセンターの設定] → [マクロの設定]
2. 「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」に
   チェックを入れる（ビルド完了後は元に戻して構いません）。

## 2. 自動ビルド手順（推奨、主にWindows向け）

1. 新規の空白ブックを開く。
2. `Alt + F11` でVBE（Visual Basic Editor）を開く。
3. [挿入] → [標準モジュール] で新しいモジュールを作成する。
4. `modBuildTool.bas` の内容をすべてコピーし、貼り付ける。
5. イミディエイトウィンドウ（`Ctrl+G`）に `BuildWorkbook` と入力して
   `Enter` を押す。
6. フォルダ選択ダイアログが表示されるので、リポジトリ内の
   `vba/modules` フォルダを選択する
   （ダイアログが使えない環境ではフォルダのフルパスの入力を求められる）。
7. 保存先ダイアログが表示されるので、ファイル名・保存場所を指定する
   （既定のファイル名: `評価データ分析ツール.xlsm`）。
8. 「ビルドが完了しました」と表示されれば完了です。

ビルドが完了すると、以下が自動的に実行されています。

- `vba/modules/*.bas` の全モジュールのインポート
- `vba/ThisWorkbook.txt` の内容を `ThisWorkbook` コードモジュールへ追記
- `mod_UI.SetupAllSheets` の実行（6画面・全テーブル・全ボタン等の初期構築）
- .xlsm 形式での保存

### Mac版での注意事項

Mac版ExcelもVBA・VBE・フォームコントロール・xlsm・箱ひげ図チャートなど、
本ツールが使用する機能はいずれもサポートしています。ただし自動ビルド
ツール（`modBuildTool.bas`）は以下の点でWindowsほど確実ではありません。

- Windowsの「VBA プロジェクト オブジェクト モデルへのアクセスを
  信頼する」に相当する設定がMacのメニュー構成には無い、または
  バージョンによって挙動が異なります。`BuildWorkbook` 実行時に
  VBAプロジェクトへアクセスできずエラーになる場合があります。
- フォルダ選択ダイアログ（ソースフォルダ選択）がMacでは動作しないことが
  あるため、その場合は自動的にパス直接入力（InputBox）に切り替わります。
- VBEの起動は `Alt+F11` ではなく、[ツール]メニュー →[マクロ]→
  [Visual Basic Editor] を使用します。

**自動ビルドがうまくいかない場合は、次の「手動ビルド手順」を使ってください。
手動手順はプログラムからのVBAプロジェクトアクセスに依存しないため、
Mac・Windowsを問わず確実に動作します。**

## 3. 手動ビルド手順（自動ビルドが使えない場合。Macでの標準手順としても推奨）

社内ポリシー等で「VBA プロジェクト オブジェクト モデルへのアクセスを
信頼する」を有効化できない場合や、Mac環境では、以下の手順で手動構築できます。

1. 新規ブックを開き、`.xlsm`（マクロ有効ブック）として保存する。
2. VBEを開く（Windows: `Alt+F11` ／ Mac: [ツール]-[マクロ]-
   [Visual Basic Editor]）。
3. VBEの左ツリーで [ファイル] → [ファイルのインポート] を
   `vba/modules` 配下の `.bas` ファイルすべてに対して繰り返す
   （9ファイルとも同じ手順で1つずつ読み込む）。
4. VBEツリーの `ThisWorkbook` をダブルクリックし、
   `vba/ThisWorkbook.txt` の内容をそのまま貼り付ける。
5. イミディエイトウィンドウ（表示 → イミディエイトウィンドウ）で
   `mod_UI.SetupAllSheets` と入力して実行する。
6. ブックを上書き保存する。

## 4. ビルド後の確認（セルフチェック）

1. 「ホーム」画面が表示され、5つの画面ボタンが機能すること。
2. 「データ取込」で外部Excel（サンプルデータ等）を1件取り込めること。
3. 「分析」で年度・クラス・評価項目を選び、3種類のグラフと統計表が
   表示されること。
4. 「設定」の評価項目テーブルで重みを変更し、「反映」で総合評価が
   再計算されること。
5. 「ログ」に操作履歴が記録されていること。

これらが正しく動作しない場合は、`docs/07_保守マニュアル.md` の
「トラブルシューティング」を参照してください。

## 5. 画面が壊れた場合の修復

ボタンやグラフが誤って削除された、またはレイアウトが崩れた場合は、
`.xlsm` を開いた状態でマクロ実行ダイアログ（Windows: `Alt+F8` ／
Mac: [ツール]-[マクロ]-[マクロの表示]）から `SetupAllSheets` を実行することで
画面を初期状態へ再構築できます（データ本体（T_Scores等）は変更されません）。
